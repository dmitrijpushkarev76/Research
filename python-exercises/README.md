# Python Exercises

Basic Python practice problems.

1. `01_max_of_three.py` - maximum of three numbers
2. `02_sum_list.py` - sum all numbers in a list
3. `03_multiply_list.py` - multiply all numbers in a list
4. `04_reverse_string.py` - reverse a string
5. `05_factorial.py` - factorial of a number
6. `06_in_range.py` - check if a number falls within a range
7. `07_count_case.py` - count upper and lower case letters
8. `08_unique_list.py` - list with distinct elements
9. `09_is_prime.py` - check whether a number is prime
10. `10_even_numbers.py` - print even numbers from a list
11. `11_perfect_number.py` - check whether a number is perfect
12. `12_palindrome.py` - check whether a string is a palindrome

Run any of them with:

```
python3 01_max_of_three.py
```
